# Origins Legacy — Addon Converter (`gh-pages`)

Static GitHub Pages site for converting simple 1.20.1 Fabric Origins addons into NeoForge (`javafml`) mod `.jar` files for **Minecraft 1.21.1 – 26.3**.

## Fonts
`style.css` prioritizes **`Minecraft Ten`**, **`Minecraft Five`**, and **`F77 Minecraft`** when installed locally, with crisp web pixel fallbacks (`Silkscreen`, `Minecraft`, `Press Start 2P`).

If you want to self-host `.woff2` files for visitors without those fonts installed locally, place them in a `fonts/` folder and add `@font-face` rules at the top of `style.css`.
